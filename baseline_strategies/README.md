# baseline_strategies
> 多资产基准组合优化模块，为项目《面向多资产配置的大语言模型风险反馈与自适应决策研究》提供基准策略

## 模块职责
本模块仅接收上游 `data_processing` 输出的协方差矩阵，实现三类经典资产配置策略；**250日滚动窗口、收益率预处理、数据校验、时序切片全部由上游链路负责，本模块不实现窗口逻辑**。

## 支持策略
1. **等权策略 Equal Weight**：各类资产权重均等分配
2. **最小方差策略 Minimum Variance**：在权重和为1、权重非负约束下，最小化组合方差
3. **风险平价策略 Risk Parity**：使得每一类资产的风险贡献相等

## 接口约定
- 输入：协方差矩阵（上游固定传入250交易日窗口计算得到的协方差）
- 输出：资产权重字典，统一返回格式
- 异常：协方差矩阵非法、非正定、维度不匹配时主动抛出异常

## 当前尚待解决问题
1. 样本协方差矩阵估计噪声较高，高维情形下易病态，影响组合权重稳定性。
2. 窗口固定为250日，无法随市场风险状态自适应调整。
3. 优化目标未纳入交易成本与换手率约束，调仓幅度缺乏限制。
4. 当前风险平价仅基于波动率，尚未实现多维度风险的均衡配置。
