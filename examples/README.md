# examples/ —— 模拟输入（synthetic_test）

本目录只放**测试与演示用的模拟数据**，不得作为正式主实验输入。

## mock_weights.csv

- 只有两期模拟决策（2026-09-30、2026-10-30），用来演示「信号日 → 次日收盘成交」的落地路径。
- 两期都只给资金权重、不给风险预算，用来演示评审口径第 3 条：预算与权重分开传递，
  缺省时沿用上一期有效预算，绝不把 target weight 复制成 budget。
- 正式主实验必须使用 1 号 `llm_decision` 或 3 号 `baseline_strategies` 的**全样本**输出，
  按同一列名（date, 510300, 511010, 518880, budget_510300, budget_511010, budget_518880）落盘。

## 列名

| 列 | 含义 |
| --- | --- |
| date | 信号日（当月最后一个共同交易日） |
| 510300 / 511010 / 518880 | 目标资金权重，合计必须为 1 |
| budget_* | 同一期生效的风险预算；三列全空表示该期没有新预算 |
