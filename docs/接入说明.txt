1号与4号离线对接

运行只依赖 Python 标准库。risk_metrics/risk_feedback.py 实现4号计算。
risk_metrics/risk_integration.py 使用 data_processing/feature_builder.py 生成市场特征，
并调用 interfaces/risk_decision.py 构建分组输入和校验预算。

真实持仓入口
提供UTF-8 CSV，列的顺序须严格为
as_of_date,group,w_510300,w_511010,w_518880,budget_510300,budget_511010,budget_518880,cost_rate

每行是一个交易日、一个实验组。group为A/B/C/D。
w_* 是当日收益发生前的实际资金权重，含当日已执行调仓。
budget_* 是该日实际生效的风险预算。二者均须非负且各自合计1。
cost_rate 是当日费用除以期初组合净值，必须明确填写，零费用填0。
每日净收益为 sum(w_i * r_i) - cost_rate。费用按资产收盘价值比例扣除。
收盘权重按收益漂移，供RC计算和下期求解起点使用。
持仓必须逐交易日记录，不能用月度目标权重直接冒充日度实际权重。
各组独立计算，不能把一组的持仓复制为所有组的真实运行历史。
B至少60日持仓，C/D至少270日连续持仓及310日市场数据。
D的比较日须有该组实际持仓，且比较日前有250日市场数据。
A生成输入时不需持仓反馈。若做预算转权重，A也须提供截止日持仓和生效预算。
user_supplied只表示用户提供，程序无法鉴定历史记录真实性。

计算口径
收益为20/60日几何累计，波动为样本标准差乘sqrt(250)。
协方差与CVaR用最近250日。CVaR为损失最差5%的加权均值，250日下取
最差12日及第13日的一半权重，尾部全为收益时允许CVaR为负值。
回撤以所提供组合历史起点净值1计，使用含费用净值。
回撤预警为最近3日均低于-8%。波动参考分布为截止日前250个20日滚动波动，
80%分位采用线性插值。股债相关为60日相关，其Z分数使用截止日前250个
60日相关观测的均值与样本标准差。参考分布排除当前信号日。
RC为收盘实际权重在250日协方差下的方差贡献比例，允许负RC。
预算偏差为RC减当前实际生效预算，Neff为1/sum(RC_i^2)。
集中度仅进入D，含三个资产的RC及Neff。C的预警仅回撤、波动、相关三项。
回撤归因为最近净值高点到当前的逐日资产贡献，按日初净值/峰值净值加权，
单列transaction_cost，四项之和等于当前回撤。历史起点前无交易日时start为空。
风险变化按明确提供的base-date比较，不隐式选择一年或一个月。
对RC%作权重、波动率、相关性的一阶方向导数分解，另存residual，
三项加残差等于RC%实际变化。有限差分步长为1e-5。
上述预警参考窗口、CVaR分位边界、成本归因和变化残差是本次实现补定的口径，
后续应与4号和5号核对。初始样本不足时报错，不以0或模拟值填补。

预算求解
可提供一个JSON文件，顶层恰为A/B/C/D，每组是原有模型决策对象。
至少含as_of_date、decision_status=ok、risk_budget三个字段。
保持1号既有校验，模型预算三个分量均须严格在(0,1)内且合计1。
先按0.5旧预算+0.5模型预算平滑，再按250日协方差求解。
solve_weights(b,cov,w0=None,max_iter=200,tol=0.005)输出weights、rc_pct、
iters、converged等字段。支持非负预算，0预算资产分配0资金权重。
默认固定点迭代，负RC或迭代停滞时改用坐标下降。
非正定协方差需要对应原始收益样本，作Ledoit-Wolf收缩后求解。
独立调用可用samples参数传样本。全零波动等仍无法求解的情况明确报错。
不收敛时输出fallback_previous，沿用收盘权重和旧预算，并保存求解诊断。
生成的weight_proposals.json为待回测端执行的提案。执行时点限T+1月首交易日。
最新数据后没有下一交易日时，日历字段为空，等待回测端提供后续交易日。

真实文件准备好后，在项目根目录运行
python -B -E -S -m risk_metrics.risk_integration data/unified_returns.xlsx --holdings "实际日度持仓.csv" --as-of 2026-11-20 --base-date 2025-11-20
有四组决策JSON时追加 --decisions "四组决策.json"
输出默认保存到risk_metrics/risk_runs下的独立run目录，integration_report.json记录输入校验值、
计算截止日、反馈审计、结果校验值和API调用状态。成功前不发布完整结果目录。
